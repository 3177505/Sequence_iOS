1. Co se tu vlastně děje (bez kódu)

Existuje velký hotový model Stable Diffusion 1.5 — umí kreslit z anglického textu (promptu), protože byl kdysi natrénovaný na obřím množství obrázků z internetu. Ty ho u sebe nepíšeš od nuly.

LoRA je malý soubor navíc: na tvém PC se z tvých fotek v public/4_Research naučí „přisadit“ se k modelu — typicky barvy, styl nebo opakující se motiv. Výsledek ukládáme do ml/outputs/lora-run.

Generování: při research-folder-training.ps1 jdou PNG do outputs/gen-lora-… v kořeni Sequence; ručně voláš ml/generate.py s --out-dir (např. outputs/gen z kořene).

2. Dvě možné cesty — tento repozitář vs Z-Image (Ostris)

Oba směry řeší „chci, aby AI znala můj vizuál“, ale nejde o totéž programově. V repu je jako hlavní linka SD 1.5 + LoRA ve složce ml/. Z-Image s Ostris ai-toolkit je jiná větev: jiný základní model, jiná instalace (vlastní repozitář, YAML, často víc kroků).

Doporučeno v tomto projektu

SD 1.5 + LoRA (ml/)

Skripty už jsou tady: launch_train, generate.py, jedna sada knihoven v ml/.venv. Dokumentace i tlačítka v prohlížeči počítají s tím. Výchozí cesta, pokud chceš méně rozcestí a držet vše v Sequence.

Volba navíc

Z-Image + Ostris

Chceš-li konkrétně Z-Image a ekosystém ai-toolkit, jde o samostatný setup mimo jednoduchý jeden-sloupec ml/. V repu máme stránku ML toolkit (SD LoRA z 4_Research, volitelně Z-Image / Ostris a .txt k obrázkům). Není to „špatně“ — je to jiný nástroj a jiný model, ne náhrada téže příručky řádek po řádku.

Shrnutí: začni u SD 1.5 + LoRA v ml/. K Ostris / Z-Image přejdi, až budeš chtít záměrně ten druhý workflow.

3. Počítač, Windows a ovladač NVIDIA

Trénink LoRA je na CPU možný, ale velmi pomalý. Pro smysluplnou rychlost počítej s Windows nebo Linuxem a kartou NVIDIA s aktuálním ovladačem ze stránek výrobce.

Apple Silicon (Mac) umí některé věci přes MPS, trénink ale obvykle zůstane nepohodlně dlouhý; generování je o trochu snesitelnější. Pro těžký trénink je fér mít dedikované PC s NVIDIA.

4. Virtuální prostředí, PyTorch s CUDA, accelerate

Vše se děje v podsložce ml/ ve virtuálním prostředí ml/.venv, aby se knihovny netloukly s jiným Pythonem na systému.

Pořadí na stroji s NVIDIA: nejdřív z oficiální stránky PyTorch nainstaluj torch + torchvision s CUDA pro tvůj systém (viz odkaz v ml/README.md), pak pip install -r requirements.txt, pak jednorázově accelerate config a odpověz jako pro jedno běžné GPU.

Ověření, že GPU vidí PyTorch (v aktivovaném ml/.venv): 

python -c "import torch; print(torch.cuda.is_available(), torch.cuda.get_device_name(0) if torch.cuda.is_available() else '')"

Podrobný seznam příkazů je v ml/README.md a v RUN.md u kořene projektu.

5. Obrázky ve složce 4_Research

Tréninkové snímky dáváš do stromu public/4_Research (může být vnořený). Při startu tréninku se z nich automaticky vytvoří plochá kopie v ml/data/instance_flat (skript ml/collect_instance_images.py), protože DreamBooth krok očekává jednu složku se soubory.

Společný text pro všechny snímky je v logice tréninku jako jeden instance prompt (v ml/launch_train.py); pokud bys chtěl u každého obrázku vlastní popisek, řeší se to samostatnými .txt soubory — např. u větve Z-Image / Ostris ml/zimage_sidecar_captions.py a stránka ML toolkit.

6. Trénink LoRA (spuštění)

Spouštíš vždy z kořene repozitáře (složka, kde leží ml/ a public/), aby cesty seděly. První běh stáhne oficiální skript tréninku do ml/vendor/. Váhy končí v ml/outputs/lora-run.

Délku můžeš zkrátit proměnnou MAX_TRAIN_STEPS (např. 200 na slabším stroji). Obnovení od posledního uloženého stavu: RESUME=1 (Linux / macOS v bash) nebo set RESUME=1 (Windows cmd) před příkazem — viz ml/README.md.

macOS / Linux

./ml/launch_train.sh

nebo: python ml/launch_train.py s aktivním ml/.venv podle README.

Windows (cmd, kořen projektu)

ml\launch_train.bat

Skript uvnitř zavolá ml\launch_train.py Pythonem z ml\.venv.

Soubor public/251205_cc8_gpu_accelator.py s tím nesouvisí — to je jiná experimentální hra s klasifikátorem, ne tento LoRA trénink.

7. Generování PNG

S aktivovaným ml/.venv a pracovním adresářem ml (kvůli cestám outputs/…):

Se LoRA (po tréninku)

cd ml
source .venv/bin/activate
python generate.py --lora outputs/lora-run --prompt "a sksseq photograph, research mood, detailed" --out-dir outputs/gen --count 2

Windows: .venv\Scripts\activate místo source.

Bez LoRA (základní SD 1.5)

python generate.py --prompt "a sksseq photograph, abstract" --out-dir outputs/gen --count 2

Výstupní soubory jsou typicky out_00.png, out_01.png v outputs/gen-lora-… po research-folder-training.ps1, případně v libovolné složce zadané jako --out-dir u generate.py. Prompt piš anglicky; „sksseq“ drž konzistentní s tréninkem.

8. Tlačítka v prohlížeči, Gradio, další čtení

ML průvodce (tlačítka) funguje při běžícím npm run dev a volá lokální API, které spouští stejné Python skripty (viz text přímo na té stránce). Není to náhrada za přečtení kroků výše, ale zkratka, když už máš vše nainstalované.

Gradio (ml-gui/app.py) otevírá druhé okno s tréninkem a náhledem generování — stále stejné ml/.venv, popis v ml-gui/README.md. Dva tréninky současně nespouštěj.

Textové soubory: ml/README.md, RUN.md. Stránka ML toolkit pro průvodce z 4_Research a volitelný Ostris.
