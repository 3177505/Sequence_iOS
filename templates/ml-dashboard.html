ML průvodce (Windows + tlačítka)

Kompletní návod krok za krokem (včetně Linuxu / Macu, tréninku a generování): ML příručka.

Tato stránka je myšlená pro Windows: jednou otevřeš Terminál (PowerShell nebo cmd), pustíš dev server, pak používáš tlačítka v prohlížeči. Tlačítka nespustí nic samy o sobě — musí běžet Node na tvém PC (npm run dev), protože prohlížeč jen volá lokální API, které spouští ml\.venv\Scripts\python.exe a skripty v ml\.

Gradio

* Druhé rozhraní ke stejnému ML (trénink / generování v druhé kartě) — až pustíš ml-gui, otevři v prohlížeči http://127.0.0.1:7860/ a postup v README ve ml-gui. Dva tréninky najednou nespouštěj.

Nejdřív v terminálu (Windows)

  1. Node.js nainstalovaný (LTS). Ověř: node -v a npm -v.
  2. Přejdi do kořene projektu Sequence (kde je package.json), např.: 
    cd C:\Users\TvojeJmeno\Dropbox\__AVU\_ACT\Sequence
    (cestu uprav podle umístění u tebe — Dropbox, disk D:, …)
  3. Jednorázově: npm install
  4. Python venv pro ML (jednorázově, v podsložce ml): 
    cd ml
py -3 -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
pip install "numpy>=1.26,<2" diffusers==0.32.2 "huggingface-hub>=0.34.0,<1.0"
accelerate config
cd ..
  5. Spusť dev server a nech okno otevřené: 
    npm run dev
    Uvidíš něco jako localhost:3000 — otevři v Edge / Chrome adresu http://localhost:3000/ml-dashboard.html

API pro tlačítka vypneš: v cmd před npm run dev dej set SEQUENCE_ML_API=0 — v PowerShellu: $env:SEQUENCE_ML_API="0" ; npm run dev

Mac / Linux: stejné, jen aktivace venv je source .venv/bin/activate a cesta k Pythonu ml/.venv/bin/python3. Stránka funguje stejně.
