# Sequence

Not an iOS app, it's an process overview of dual-screen web exhibition prototype. Image generation (ML) is local only — NVIDIA GPU on Windows or Linux; Mac is possible but slow. The public site is a static preview: [https://sequence-ios.onrender.com](https://sequence-ios.onrender.com)

## What’s included

- Dual-screen color prototype
- Reddit sequence
- Research image blend
- Data videos
- Exhibit images (two-pane and fullscreen left/right)
- Concept, research gallery, inspiration, semiotic
- Wiring guide
- Model screenshots
- ML manual, CLI, dashboard, toolkit
- Manufacturing notes
